JSON – das Datenformat

JSON (JavaScript Object Notation) ist ein Textformat für strukturierte Daten. Menschen können es lesen, und praktisch jede Programmiersprache kann es verarbeiten. Alle MCP-Nachrichten sind JSON.

{
  "name": "Kern-7",
  "ports": 6,
  "online": true,
  "temperatur": 41.5,
  "module": ["Datenbank", "Kalender"],
  "besitzer": null,
  "position": { "raum": "B204", "regal": 3 }
}
DatentypBeispielRegel
String (Text)"Kern-7"immer in doppelten Anführungszeichen
Zahl6, 41.5, -3ohne Anführungszeichen, Dezimalpunkt statt Komma
Booleantrue, falseklein geschrieben
nullnull„kein Wert“, klein geschrieben
Array (Liste)[1, 2, 3]eckige Klammern, Werte mit Komma getrennt
Objekt{"a": 1}geschweifte Klammern, Schlüssel: Wert-Paare

Typische Fehler: Schlüssel ohne Anführungszeichen · einfache statt doppelte Anführungszeichen · Komma nach dem letzten Element · Kommentare (gibt es in JSON nicht) · True statt true

JSON-RPC 2.0 – Befehle über die Leitung

RPC heißt Remote Procedure Call: Ein Programm ruft eine Funktion auf, die auf einer anderen Maschine (oder in einem anderen Programm) läuft. JSON-RPC legt fest, wie solche Aufrufe als JSON aussehen. MCP verwendet genau dieses Format. Es gibt drei Arten von Nachrichten:

① Request (Anfrage)

{
  "jsonrpc": "2.0",
  "id": 7,
  "method": "tools/list",
  "params": {}
}

Hat eine id und erwartet eine Antwort. method sagt, was passieren soll.

② Response (Antwort)

{
  "jsonrpc": "2.0",
  "id": 7,
  "result": { "tools": [] }
}

Trägt dieselbe id wie die Anfrage. Enthält entweder result oder error.

③ Notification (Mitteilung)

{
  "jsonrpc": "2.0",
  "method": "notifications/initialized"
}

Keine id, und darauf kommt keine Antwort. Wie ein Funkspruch an alle.

Wenn etwas schiefgeht: das Error-Objekt

{
  "jsonrpc": "2.0",
  "id": 8,
  "error": { "code": -32601, "message": "Method not found" }
}
CodeBedeutungBeispiel
-32700Parse errorDie Nachricht ist kein gültiges JSON.
-32600Invalid RequestGültiges JSON, aber keine gültige Anfrage (z. B. "jsonrpc" fehlt).
-32601Method not foundDie Methode gibt es auf dem Server nicht.
-32602Invalid paramsParameter fehlen oder sind falsch.
-32603Internal errorInterner Fehler im Server.

Merke: "jsonrpc": "2.0" steht in jeder Nachricht, und zwar als String. Die id ist eine Zahl oder ein String und ordnet Anfrage und Antwort einander zu, auch wenn mehrere Anfragen gleichzeitig unterwegs sind.
