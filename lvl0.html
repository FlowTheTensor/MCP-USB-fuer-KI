LVL 0 · Station 1 · Grundlagen

Ein Kern ohne Anschlüsse

Ein großes Sprachmodell (LLM) kann genau eine Sache: Text rein, Text raus. Es hat beim Training sehr viel gelernt, aber nach dem Training ist es abgeschlossen.

Ohne Anschlüsse kann der Kern …

  • ✗ nicht wissen, wie das Wetter heute ist
  • ✗ keine Datei auf deinem Rechner lesen
  • ✗ nicht in der Schuldatenbank nachsehen
  • ✗ keinen Termin eintragen und keine Mail senden

Mit Anschlüssen kann der Kern …

  • ✓ aktuelle Daten abrufen (Kontext bekommen)
  • ✓ Werkzeuge benutzen (Datenbank, Dateien, APIs …)
  • ✓ Aktionen in der echten Welt auslösen
  • ✓ Ergebnisse prüfen und weiterarbeiten

Model Context Protocol heißt wörtlich: ein Protokoll (feste Regeln für die Kommunikation), mit dem ein Modell an Kontext kommt, also an die Informationen und Werkzeuge, die es für eine gute Antwort braucht.

LVL 0 · Station 2 · Interaktiv

Das Kabelchaos

Stell dir vor, jede KI-Anwendung bräuchte für jedes Werkzeug ihren eigenen, speziellen Adapter. Genau so war es vor MCP. Verändere die Anzahl und vergleiche.

Ohne Standard braucht man N × M Einzellösungen. Mit einem gemeinsamen Protokoll baut jede KI-Anwendung einen MCP-Client und jedes Werkzeug einen MCP-Server: zusammen nur N + M.

Warum „USB für KI“?

USBMCP
Computer mit USB-BuchsenHost: die KI-Anwendung (z. B. ein Chat-Programm oder eine Programmierumgebung)
Die einzelne USB-BuchseClient: eine Verbindung zu genau einem Server
USB-Gerät (Maus, Stick, Drucker)Server: Programm, das Werkzeuge oder Daten anbietet
Gerät meldet sich an und sagt, was es kannHandshake mit initialize und Capabilities
USB-Spezifikation: Stecker, Signale, AblaufMCP-Spezifikation: Nachrichtenformat (JSON-RPC), Ablauf, Fähigkeiten
KabelTransport: lokal über stdio oder übers Netz über HTTP

MCP wurde im November 2024 von Anthropic als offener Standard veröffentlicht. Inzwischen unterstützen ihn viele Anbieter von KI-Anwendungen und Werkzeugen, und er wird unter dem Dach der Linux Foundation weiterentwickelt. Genau das macht einen Standard wertvoll: Alle halten sich an dieselben Regeln.
