Ein echter Server: SQLite-per-MCP

    
So kurz kann ein echter MCP-Server sein. FastMCP baut aus dem Funktionsnamen, den
      Typangaben und dem Docstring automatisch den tools/list-Eintrag samt inputSchema.


from fastmcp import FastMCP

mcp = FastMCP("SQLite Schul-Datenbank")

@mcp.tool()
def query_database(query: str) -> str:
    """Führt eine SQL SELECT-Abfrage auf der Schul-Datenbank aus."""
    if not query.strip().upper().startswith("SELECT"):
        return "Fehler: Nur SELECT-Abfragen sind erlaubt!"
    ...  # Abfrage ausführen, Ergebnis als JSON zurückgeben

if __name__ == "__main__":
    mcp.run(transport="stdio")

LVL 5 · Station 3 · Ausblick experimentell

    
Ausblick: WebMCP – Tools direkt in der Webseite

    
MCP verbindet KI mit eigenen Server-Programmen. Doch viele Werkzeuge stecken heute in Webseiten:
      Stundenplan, Onlineshop, Fahrplanauskunft. Ein KI-Agent müsste sie mühsam „wie ein Mensch“ bedienen: Seite lesen, Knöpfe suchen, klicken.
      WebMCP überträgt die Idee von MCP in den Browser: Eine Webseite meldet ihre Funktionen als Tools beim Browser an,
      und ein Agent kann sie gezielt aufrufen.

    

      
MCPWebMCP

      
        
Wo laufen die Tools?in einem eigenen Server-Programm (lokal oder im Netz)direkt in einer Webseite, als JavaScript

        
KommunikationJSON-RPC über stdio oder HTTPüber eine Schnittstelle des Browsers

        
Wer ruft auf?ein Host bzw. Agent, z. B. Claude Desktopein KI-Agent im oder am Browser

        
Anmeldungmuss der Server selbst lösennutzt die bestehende Sitzung des Nutzers auf der Seite

        
Reifeetablierter offener StandardEntwurf, experimentell

      
    

    
Das Prinzip kennst du schon: ein Tool mit Name, Beschreibung und Eingabe-Schema.


// Vereinfachtes Prinzip – die genaue Schreibweise der API ändert sich noch
modelContext.registerTool({
  name: "stundenplan_anzeigen",
  description: "Zeigt den Stundenplan einer Klasse an.",
  inputSchema: {
    type: "object",
    properties: { klasse: { type: "string" } },
    required: ["klasse"]
  },
  async execute({ klasse }) {
    const plan = await ladeStundenplan(klasse);   // nutzt die Anmeldung des Nutzers
    return { content: [{ type: "text", text: plan }] };
  }
});

    
Stand November 2026: WebMCP ist ein Entwurf einer Arbeitsgruppe beim W3C
      (Web Machine Learning Community Group), vor allem vorangetrieben von Google und Microsoft, und noch kein offizieller Standard.
      Nur Chrome bietet bisher eine Test-Umsetzung an, andere Browser unterstützen es nicht. Auch der Name der Schnittstelle ändert sich noch.
      Aktueller Stand: Spezifikationsentwurf.

    
Zum Nachdenken: Die Tools laufen mit der Anmeldung des Nutzers, ein Agent könnte also z. B. im Namen
      einer Schülerin Nachrichten verschicken. Was bedeutet das für Human-in-the-Loop und für die Gefahren aus LVL 4?
